Frontend for the **Garage Repair Tracker**, built using **React + Vite + Tailwind CSS**.  
It connects to the API and provides a simple, intuitive UI for managing repair jobs.

---

## Features

- Each job records the id of the device that created it
- Add jobs by **license plate**
- Update job **status** in real-time
- Delete jobs from the list
- Optimistic UI updates
- Mobile and desktop-friendly layout
- Shared domain types from `@garage/shared`

---

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Shared domain models (`@garage/shared`)
